## Notas técnicas para generación

- **Iconos**: exportar en PNG de 1024×1024 píxeles con fondo transparente, luego convertir a WebP con calidad 85.
- **Fondos**: generar en 1920×1080 o 1920×960, con paleta cálida (amanecer/atardecer) y elementos argentinos sutiles.
- **Avatares**: 1024×1024, retrato tipo busto, fondo de color sólido acorde al perfil.
- **Eventos**: 1920×960, composición narrativa clara que deje espacio superior para texto de título.
- Después de generarlas, ejecutar `python scripts/generate_thumbnails.py` para crear las versiones 128×128 de los nuevos iconos.
